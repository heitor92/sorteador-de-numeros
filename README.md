# Sorteador de Números

Aplicação para sorteio de números aleatórios, útil para rifas, sorteios, loterias e outras situações em que seja necessário gerar números aleatórios de forma justa e transparente.

Projeto criado no curso Full-Stack da Rocketseat💜🚀.

Para visualizar acesse o link 👉 [https://heitor92.github.io/sorteador-de-numeros/](https://heitor92.github.io/sorteador-de-numeros/).


## Funcionalidades

- Sorteio de números aleatórios dentro de um intervalo configurável (mínimo e máximo)
- Opção de sortear múltiplos números de uma vez
- Garantia de números únicos (sem repetição), quando habilitado
- Exibição clara do resultado do sorteio
- Interface simples e intuitiva

## Como usar

1. Defina o intervalo do sorteio (número mínimo e máximo)
2. Informe a quantidade de números a serem sorteados
3. Clique no botão de sorteio
4. Veja o resultado exibido na tela

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/sorteador-de-numeros.git
```

2. Acesse a pasta do projeto:

```bash
cd sorteador-de-numeros
```

3. Abra o arquivo `index.html` no navegador ou utilize uma extensão de servidor local (como o Live Server do VS Code).
